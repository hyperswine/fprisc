# FP-RISC 0.13.0 released

Status: published, 2 November 2026.
[Release v0.13.0](https://github.com/hyperswine/fprisc/releases/tag/v0.13.0),
built from `58e0aed` (main with the version set to `0.13.0`). Main is
`0.14.0-dev` again from the next commit.

- **Archive.** `fprisc-0.13.0-macos-arm64.tar.gz`, 19.1 MB, SHA-256
  `1a473349a1a3df1968ac15806162fedaba2f5fce0c9052adefedeb5a89a75eed`. It is
  self-contained: libgit2, libarchive and their dependencies load from
  `libexec/fprisc/lib` by `@rpath`
  ([self-contained toolchain](2026-11-01-SELF-CONTAINED-TOOLCHAIN.md)).
- **Delivery.** There is no `fprisc` formula any more. The entry was added to
  the tap's `toolchains/fprisc.json` (tap `43f0eba`), so
  `fprmeta install 0.13.0` installs it beside 0.12.0
  ([fprmeta published](2026-11-02-FPRMETA-PUBLISHED.md)).
- **Qualification.**
  - `tools/toolchain-install-check.py --release`: all 51 steps, with
    `/opt/homebrew` denied.
  - `make unit-tests`: passed.
  - Installed through `fprmeta install --archive`: `fpr new` then `fpr test`
    passed; the inventory and logbook projects' `sol project.sol test` passed.
- **Since 0.12.0.** The project workflow (`fpr.toml`, `fpr new`, `check`,
  `test`, `doctor`, exact pins), typed Core list fusion and case of known
  constructor with the trap-safety fixes, cost-sized regions work, the frozen
  Cabal plan and the bundled libraries.

The `fprmeta` formula still depends on Homebrew's libgit2 and libarchive,
because the list still offers 0.12.0, which loads them from `/opt/homebrew`.
