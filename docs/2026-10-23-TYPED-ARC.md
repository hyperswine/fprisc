# Builtin ARC and raw units through typed RV64 codegen

This increment follows `17a70ac` and replaces the remaining builtin ARC/raw
function emission with typed lowering and direct RV64 selection. The
[complete migration goal](2026-10-23-TYPED-IR-COMPLETION.md) remains open:
legacy rollback, native-metric consumers and final deletion are separate work.

## Ownership and representation contract

`BuiltinArc` now admits the fixed-stack, no-actor-fuel policy. The existing
representation and ownership passes still run before typed lowering. They
prove raw Word/Addr/float conventions, insert retains and releases, attach
field-kind descriptors, sequence cleanup before tail transfers and refuse
unsupported indirect calls, partial applications and interrupt effects.
The runtime ABI has not changed; RV32 ARC remains unsupported as before.

Typed `OMake` selects `fpr_builtin_alloc_adt(bytes, field_count)` under this
policy. It writes the type/variant and evaluated fields after allocation.
The explicit `$arc.setLayout` call installs the existing raw/managed field
descriptor. Managed values retain their consuming C adapters, including
alias-result retains. Generated function sections preserve linker garbage
collection, weak library stubs and C export trampolines.

`$sym.name` selects a linker address for allocation-free raw units. The
self-hosted `machine/builtin/heap.fpr` therefore compiles through the same
typed path. Its exported allocation, release and layout ABI is unchanged.

The native preparation now applies the same Core normalization the old
ownership-aware generator used. Pure nullary constructors remain immortal
objects; effectful nullary definitions remain calls. A nullary self-tail
transfer reuses its existing frame. Static-stack loops report honest
`UNBOUNDED` native segments rather than inventing actor preemption bounds.

## Direct raw and checked integer selection

The selector handles the closed raw-adapter vocabulary after ownership
lowering. Word bit/arithmetic operations wrap at 64 bits, Addr conversions
retain their raw representation, and aligned memory operations preserve
the runtime's widths, signed/tagged small values and volatile access order.
Invalid shift/bit indices and alignment take a selected CFG edge to the
audited C adapter with the original arguments.

Checked Int addition/subtraction validate the signed 63-bit result;
multiplication checks the high product and result range; division checks
zero and the signed payload range. Failures retain the consuming adapter's
diagnostics. Comparisons of Ints are direct. General equality only bypasses
the consuming adapter when both operands are tagged immediates. Tagged
immediates also need no retain/release, exactly as both builtin heaps specify;
managed pointers retain their calls and reference-count work.

These operations are selected instructions and control-flow edges handled
by the shared allocator and verifier. They do not consume RISC-V text from
the old generator. The generator revision is 76; RV selection revision 16.
Runtime calls remain separately reported; instruction reports do not bound
callee internals or certify elapsed-time WCET.

## Acceptance evidence

The execution gate is `tests/check_typed_ir_arc.py --require-execution`.
It runs the existing ARC, raw/interrupt, layout and export suites under
strict native coverage, including the self-hosted allocator:

- 10,000 sharing/escape cycles in a 16 KiB heap with zero live allocations.
- A 6,000-node returned graph and 12,000-node sanitizer destruction checks.
- Effectful nullary tail recursion, separate ownership compilation and cache
  rebuilds; unsupported ownership forms remain refused.
- Raw/managed fields, floats, NaN/signed-zero equality, imported raw calls,
  checked shift/bit/alignment and Int overflow/division failures.
- 1,000 resumable interrupts with every GPR/FPR and `fcsr` preserved;
  handler restrictions and emergency-stack synchronous faults.
- Layout identities, sizes and accessors; C exports across every boundary
  type, including twelve arguments, linker symbols and weak shared stubs.
- An independent Python oracle with 879 raw-word and checked-Int checks,
  all 64 shift/bit indices, high bits, wrapping and signed boundaries.
- A negative control that removes constructor field metadata and must fail
  in the real ownership runtime.

These are RV64 QEMU-virt execution and native host ASan/UBSan results.
No physical RV64 ARC board execution or hosted CI result is claimed here.
The gate is registered in Base and as a required-execution CI step.

The full local Base sweep passes **115 jobs in 382 seconds** on four
workers, including the aggregate ARC gate and metadata negative control
([log](evidence/2026-10-23-typed-arc/base-final.log)). The legacy rollback
passes the same execution oracle separately
([log](evidence/2026-10-23-typed-arc/legacy-final.log)). The measured program
and self-hosted allocator contain 26 and 135 native functions respectively.
Compiler identity and validation scope are recorded in
[metadata](evidence/2026-10-23-typed-arc/metadata.json). Intermediate failure
logs retain the investigation history and are not passing acceptance evidence.

## Paired guest work

The initial C-adapter-only implementation was correct on the reduced
fixture but exceeded the sharing test's timeout. After raw Word/Addr
selection it still used 4.39 times the legacy guest work. Adding checked
Int selection reduced the ratio to 1.41. Preserving immortal nullary
constructors and bypassing retain/release for tagged immediates brought
the three-pair ratio to 0.9268. These rejected intermediate versions are
retained as evidence that correctness alone did not satisfy promotion.

The final paired gate uses `tools/bench-arc-typed.py`, compiling the same
program and self-hosted heap through legacy and strict typed modes of the
same compiler. Both link the real runtime with ARC exit checks enabled.
Guest `instret` surrounds generated `main`, including its allocator and
ownership work; startup and final result release are outside the counter.
The QEMU runs use deterministic `-icount shift=0`, randomized pair order,
and check the program's result on every run. Counts are guest work, not
physical board timings or a universal speedup claim.

All **31 pairs** return identical counts per variant: legacy
**1,537,312,028**, typed **1,424,802,054** guest instructions. The new/old
ratio is **0.9268**, or **7.3% fewer guest instructions** on this workload.
[Raw samples](evidence/2026-10-23-typed-arc/paired-results.json) and
[run log](evidence/2026-10-23-typed-arc/paired-final.log) are retained.
The compiler hash in the samples matches the final tested compiler.

```sh
python3 -u tools/bench-arc-typed.py --output /private/tmp/fpr-arc-paired --runs 31
python3 -u tests/check_typed_ir_arc.py --require-execution
python3 -u tests/check_typed_ir_arc.py --require-execution --backend legacy
```
