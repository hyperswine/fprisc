# Sol-only main branch (2026-11-13)

All tracked repository-owned Python and shell script files have been removed,
including extensionless boot hooks, tests, benchmarks, old reference implementations
and historical evidence scripts. The Bash sweep manifest was retired as well.
The exact removal list is in [SOL-ONLY-REMOVALS.json](2026-11-13-SOL-ONLY-REMOVALS.json).

The complete earlier implementations are preserved in the
[final legacy source release](https://github.com/hyperswine/fprisc/releases/tag/legacy-scripts-final-2026-11-13).
This is deliberate retirement, not a claim that every removed feature has been ported.
Older documents and evidence describe the archived tree; their Python/shell commands
are not supported by this branch.

## Supported direction

Core builds, image admission, packaging and contributor builds use existing Sol
programs and native compiler/SDK executables. Native C/Haskell tests and FP-RISC
program fixtures remain. `tools/sol-only-check.sol` checks the script-file policy;
CI runs the surviving build and Sol smoke checks. CI no longer claims the removed
Python/Bash regression coverage.

## Remaining restoration work

- Rebuild compiler/runtime regression, benchmark and independent-oracle coverage in Sol.
- Add Sol serial, PTY and Unix-domain-socket support or native helpers for hardware,
  interactive tests and the compiler-daemon protocol.
- Restore QOS contributor run/dev/serve, installation/disk workflows and compiler
  daemon supervision through Sol; `qbuild` retains build/app/plugin/profile/pack.
- Restore appliance boot supervision, Wi-Fi/DHCP hooks and board/VM qualification
  through Sol before enabling those configurations again.
- Replace specialist asset-generation, release-signing and deployment automation.

Make/Cabal, C/Haskell/native tools, upstream vendor scripts and CI command setup
are not repository-owned Python/Bash script files and remain in use. In particular,
ESP-IDF's external Python toolchain remains a vendor dependency. ESP-IDF build now
calls its Sol worker directly and expects the vendor environment to be configured;
flash/console automation reports that it is retired. Buildroot autostart and splash
options fail explicitly until their service implementations are restored.

## Validation of this cutover

- FP-RISC compiler rebuilt successfully; all 44 retained native Cabal suites passed.
- Sol JSON/decoder/arithmetic smoke checks passed.
- Both script policies passed; a deliberately added Python file was rejected.
- QOS host and native hello bundle built, packaged and executed successfully.
- The QOS Sol sweep also passed with `python`, `python3` and `bash` blocked on PATH.
- Both replacement CI workflow files parsed successfully.

These checks do not restore the removed test coverage or qualify physical boards,
new Linux appliance images, or ESP-IDF flashing.
