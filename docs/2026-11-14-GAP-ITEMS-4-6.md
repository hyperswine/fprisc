## Summary

Five changes on branch `hashmap`, measured on the app workloads:

1. **`split` on a one-byte separator scans bytes.** In `std/string`, `split` with a one-byte separator, and `lines`, find the next separator with a
   byte scan instead of a substring search.
2. **AArch64 add/sub immediates and fused layout tests.** `add`/`sub` take a 12-bit immediate operand. A record-layout
   test (`OTagTest`) fuses into compare-and-branch, as the other tests already did.
3. **Exact-arity applies call directly (AArch64).** A function value with nothing captured, applied to exactly its arity, is called through its code pointer inline. Before, every such
   call went through `fpr_applyN`, the C helper that copies the arguments and then switches on the arity.
4. **No call region inside a function its callers wrap.** Some functions no longer open pending regions around their own calls. The function
   must be a non-recursive call-region target that no other unit can name, and each of its references must be a saturated call that a caller wraps.
5. **Small comparators inlined into owned-map walkers.** A comparator like `Ord.int` is inlined where the walker cases on its answer, and the case is
   resolved into its leaves. No call is made and no `Ordering` is built.

`codegenRev` is 224.

## 1. split by a byte scan

`split sep s` with `strlen sep == 1` goes to `splitCharGo`, which uses
`charFrom`: a byte loop that String-scan versioning compiles to a raw scan.
`linesGo` uses the same scan for newline. The answers are unchanged, including the edge cases (empty input,
a trailing separator, adjacent separators). csv: 10.33 -> 6.56 G instructions.

## 2. AArch64 immediates and fused layout tests

- **Immediates.** `selectInstr` gets the constants of a block that fit 0..4095. `+`/`-` with such an operand
  emit `add`/`sub #imm` with the overflow check. The slow path materialises the constant
  and calls the primitive, as before. Raw (`OArithU`) adds take the immediate form directly.
- **Layout tests.** `OTagTest` joins the fusable compares: the int bit, the typeid compare, then the
  variant compare and branch.

sim 4.77 -> 4.65 G. The rest of sim's fixed cost is boxed record fields (a representation change, not attempted).

## 3. Exact-arity applies

`A.ApplyN` (n = 1..8) now begins with an inline test:

```
ldr x0, [sp, #16n]          ; the function value
tbnz x0, #0, 1f             ; an Int: the runtime traps
ldr w9, [x0]; cmp w9, #T_PAP; b.ne 1f
ldp x9, x10, [x0, #16]      ; arity, nargs
cmp x9, #n; ccmp x10, #0, #0, eq; b.ne 1f
ldr x16, [x0, #8]; ldr x0..x(n-1) from the pushed slots; blr x16; b 2f
1: (the old fpr_applyN call)
2: add sp, ...
```

This is what `fpr_applyN` does through `callf` when `nargs == 0 && arity == n`. Partial
applications, over-application and captured arguments still take the runtime path. The push discipline is
unchanged, so the slow path reads the same slots.

The effect is largest wherever a comparator or element function is a plain global, as in `Map.get`'s `getGo`.
treemap's 500,000 lookups went from about 3,000 to about 1,600 instructions each.

## 4. Nested call regions

Before, a call region wrapped every costly call in every function. So `csv`'s `step` wrapped `num`, `num` wrapped
`toInt`, and `toInt` wrapped `trim`, `trimLeft` and so on: about 11 pend/leave pairs per input line. None of the inner
ones ever trips on a short line.

The rule (ReceiveTurns `nestedOwner`) is that a function gets no call regions of its own when all of these hold:

- it is itself a call-region target (`costly`);
- it is in no recursive SCC of the unit;
- no other unit can name it (not in `shared`);
- it has at least one reference, and every reference is a saturated call from a function that wraps it.

The wrapping caller must have an interface, must not be skipped itself, and must satisfy `copyableAt`. Both the typed placement (`callTargets`) and the Core one (`callRegions`) apply the rule.

- **Visible and entry functions keep theirs.** An entry point, a function used as a value, or one another unit calls keeps its regions: its
  callers may not wrap it.
- **Why recursion is excluded.** A recursive function would hold its callees' scratch for the whole recursion.
- **A first version was unsound.** It dropped the last two conditions. That broke `regionnest`, `pendreset` and RegionInterfaces' `client n = build n`,
  an entry nobody wraps.

The sound rule keeps less: most of csv's nesting is inside std/string functions that every unit can call.
csv 6.57 -> 6.44 G, records 2.91 -> 2.88 G, wordfreq 6.84 -> 6.71 G and 314 -> 284 MB. The cheaper fix for
the rest would be the pend/leave pair itself: an inline fast path in place of two runtime calls.

## 5. Inlined comparators

When the direct-comparator rewrite applies (one known comparator for the unit's owned maps), and that comparator is an if-tree of
nullary constructor leaves, the inline applies too. It needs each leaf at most once, and the comparator may call nothing
private to its module. `Ord.int` qualifies; `Ord.string` does not, because it calls `fromInt`. The walker's

```
let o = int k k2 in case o of Less -> A | Greater -> B | Equal -> C
```

becomes the comparator's own tests with A, B and C at its leaves. No branch is copied, because each constructor
leaf appears once. `mapBodiesOf` (Reuse) now hands Reuse the functions the empty maps name, and their
constructor stubs, along with the map family's bodies.

treemap: 3.15 -> 2.82 G (inserts). Its wall time hardly moves. The walk is bound by cache misses, not instructions.

## Not done

- **Item 4, `Option`/`Result` in registers across units.** Variant returns apply only to private functions. An
  imported `toInt` or `get` would need a private clone per unit (`withImportedVariantResults` is the starting point), to save one small
  cell per call. This round's other items were cheaper wins, so it was set aside.
- **Substring views.** A substring sharing its parent's bytes is a new String representation (every primitive,
  the copy-out walks, the codecs), not a compiler pass.
- **A table representation for owned hash maps.** This is unchanged from the previous record.
