# FP-RISC 0.13.1 release

Published 2 November 2026: [v0.13.1](https://github.com/hyperswine/fprisc/releases/tag/v0.13.1).
The signed Homebrew manager index now offers the macOS ARM64 archive, requiring
macOS 27.2 or later and Apple Command Line Tools for native builds.

```sh
brew upgrade hyperswine/tap/fprmeta
fprmeta install 0.13.1
```

Installing preserves an existing default. Select this release with
`fprmeta default 0.13.1`, or use a project toolchain pin. An unversioned
`fprmeta install` selects the newest stable release from the index.

The compiler's direct project admission now follows the manager's canonical
version policy: compatible 0.x pins stay within their minor series, stable pins
exclude prereleases, and exact pins include the complete tag. Installed
`toolchain.json` supplies the release identity for admission, `new` and `doctor`.
Updating the manager alone could not change these checks inside 0.13.0.

The archive was built from clean revision
`e8fddc578308089d57bab48deb83f5257bfe6f3f` and has SHA256
`f59a88dcb48f095d71d2f067ed5c49d7421d64e0efaf86a47e1ebc5157e0495a`.
It includes the compiler, Sol, libraries and native dependency notices.
Non-system dynamic libraries are bundled and relocated.

Qualification passed 36 compiler unit suites, 13 native manager contract groups,
and 51 exact-archive installed-workflow steps. The latter denied source access,
GHC/Cabal/make/git and Homebrew, checked relocation and immutable installed files,
and exercised native builds, Sol and x86-64 execution under Rosetta.
Seven direct packaged-compiler pin cases covered accepted compatible/exact/
prerelease-minimum pins and rejected incompatible/exact-old/exact-prerelease/
noncanonical pins. The same matrix passed for QOS SDK 0.3.1.

Fresh isolated installs through Homebrew's managers used their public signed
indexes, selected 0.13.1 and SDK 0.3.1, and passed `fpr new` / `fpr test` and an
external QOS counter build. Receipt hashes match the qualified archives.
Real user stores and defaults were preserved.

records commands and results. This is hosted qualification including Rosetta;
it does not claim a new hardware deployment or broader platform support.
